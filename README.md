# Woordle

Petit jeu de lettres inspiré de Wordle, réalisé en HTML, CSS et JavaScript natif.

## État du projet

Le projet est terminé et archivé pour le moment. L’objectif était de créer le jeu et de tester sa logique, notamment la saisie des lettres et l’évaluation des propositions. Cet objectif est atteint.

Le jeu fonctionne sur ordinateur avec un clavier physique. Il pourra servir de référence pour un futur projet du même type.

## Jouer

Le but est de deviner un mot secret de cinq lettres en six essais maximum.

Après chaque proposition, les cases indiquent :

- **Vert** : la lettre est à la bonne place.
- **Jaune** : la lettre se trouve dans le mot, mais à une autre place.
- **Gris** : la lettre n’est pas dans le mot.

Commandes : saisissez les lettres avec le clavier, utilisez **Retour arrière** pour effacer une lettre et appuyez sur **Entrée** pour valider une proposition complète.
